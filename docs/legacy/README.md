# فایل‌های قدیمی (Legacy)

این دو فایل از نسخه اصلی بازی هستند و در نسخه ۲٫۰٫۰ **بارگذاری نمی‌شوند**:

- `src-nextgen.js` — لایه شهر بعدی که در نسخه اصلی هم با کامنت غیرفعال شده بود.
- `src-cinematic.js` — لایه سینمایی که در نسخه اصلی هم با کامنت غیرفعال شده بود.

دلیل نگهداری: اگر ایده‌ای از آن‌ها (مثلاً جاده‌ها، باران یا نشانه‌های سینمایی) خواستیم برگردانیم، مرجع در دسترس باشد — نه اینکه دوباره نوشته شود. برای برگرداندن هر بخش، باید آن را به‌صورت ماژول تمیز در `public/game/` بازنویسی کرد، نه اینکه فایل قدیمی مستقیم لود شود.
