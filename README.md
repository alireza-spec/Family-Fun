# Family Fun 2.3 — بازی شهر باز خانوادگی


بازی سه‌بعدی زندگی خانوادگی و شهر باز، فارسی و راست‌چین، با Three.js.
بازیکن در یک شهر کوچک زندگی می‌کند: راه می‌رود، رانندگی می‌کند، با
۲۴ شخصیت حرف می‌زند، وارد ۱۴ ساختمان می‌شود، شغل شیفتی انجام می‌دهد،
مأموریت کامل می‌کند و خانه‌اش را مدیریت می‌کند.

**نسخه: ۲٫۸٫۰** — ارتقای حرفه‌ای نسخه اصلی (تک‌فایل HTML با Three.js از CDN).

## اجرا

```bash
cd family-fun-upgrade
npm install
npm run dev      # توسعه، روی http://localhost:5173
```

برای نسخه نهایی:

```bash
npm run build    # خروجی در dist/
npm run preview  # پیش‌نمایش نسخه ساخته‌شده
```

یا پوشه `dist/` را با هر سرور استاتیک ساده سرو کنید. باز کردن مستقیم
فایل با `file://` توصیه نمی‌شود (ماژول‌های ES به سرور نیاز دارند).

## کنترل‌ها

| کار | کیبورد | لمسی |
|---|---|---|
| حرکت | WASD / جهت‌ها | جوی‌استیک پایین چپ |
| دویدن | Shift | دکمه 🏃 |
| تعامل / سوار شدن | E | دکمه اکشن |
| تعامل با نشانه جهان | Q | — |
| باران | R | — |
| دوربین | دکمه 🎥 | دکمه 🎥 |

دکمه‌های جدید در HUD: 💾 ذخیره (اسلات ۱)، 🔊 قطع/وصل صدا، 🎨 چرخه کیفیت،
🗂️ پنل اسلات‌های ذخیره با خروجی و ورودی JSON.

## تنظیمات کیفیت

در صفحه شروع یا با دکمه 🎨 می‌توان کیفیت را عوض کرد:

- **سبک:** گوشی ضعیف — وضوح ۱، سایه ۵۱۲، ذرات کم، بدون Bloom
- **متعادل:** پیش‌فرض موبایل — وضوح ۱٫۵، سایه ۱۰۲۴، بدون Bloom
- **بالا:** دسکتاپ — وضوح ۲، سایه ۲۰۴۸، Bloom فعال

کیفیت در `localStorage` با کلید `ff-quality` ذخیره می‌شود.

## ذخیره‌سازی

- ذخیره خودکار هر ۳۰ ثانیه (در صورت تغییر) و هر ۲ دقیقه.
- ۳ اسلات دستی + اسلات خودکار (۰).
- خروجی و ورودی JSON از پنل 🗂️؛ پیشرفت شامل اسم، آمار، پول، مأموریت،
  موقعیت، زمان و روز است.

## ساختار

- `index.html` + `src/main.js` — ورودی Vite؛ Three.js با npm باندل می‌شود.
- `public/game/` — کد بازی: `game-core.js` (هسته)، `textures.js`،
  `graphics.js`، `particles.js`، `quality.js`، `quests.js`، `economy.js`،
  `audio.js`، `save.js`، `ui.js`، و لایه‌های `world-overhaul.js` و
  `gameplay-overhaul.js` و `character-studio.js`.
- `public/assets/` — آیکون‌های SVG شهر.
- `docs/legacy/` — فایل‌های قدیمی غیرفعال، فقط برای مرجع.

## نسخه GTA (۲٫۰٫۱) — شهر باز، خانوادگی

بدون کشتن، بدون سلاح و بدون خشونت گرافیکی. «شبیه GTA» یعنی شهر باز،
رانندگی، پلیس و مأموریت:

- **رانندگی:** با E سوار هر ماشین نزدیک شو (ماشین‌های پارک‌شده، ترافیک و
  پلیس)؛ شتاب، ترمز، ترمز دستی (Space)، آسیب و دود، بنزین، تعمیر با R در
  گاراژ علی.
- **پلیس و وانتد:** ۱ تا ۵ ستاره؛ تصادف و رانندگی خطرناک ستاره می‌دهد،
  پنهان شدن ستاره را کم می‌کند، دستگیری = جریمه + برگشت به خانه (بدون مرگ).
- **ترافیک و عابر:** ماشین‌ها در مسیر می‌رانند و پشت چراغ قرمز می‌ایستند؛
  عابرها در پیاده‌رو راه می‌روند و از ماشین بازیکن کنار می‌کشند.
- **آب‌وهوا و شهر:** صاف، غروب، باران و مه؛ نیمکت، سطل، بیلبورد فارسی،
  فضای داخلی کافه، گاراژ و اداره پلیس (با E نزدیک درشان).
- **شخصی‌سازی:** رنگ لباس/مو، رنگ ماشین در گاراژ، چراغ حیاط خانه — همه
  در `localStorage` ذخیره می‌شوند.
- **داستان:** ۶ مأموریت زنجیره‌ای با دیالوگ سینمایی، شغل تاکسی/تحویل/پیک،
  خرید ملک (کافه، بوتیک، گاراژ) با درآمد دوره‌ای، شهرت محله‌ها، دستاوردها
  و باز شدن ماشین اسپرت در نمایشگاه.
